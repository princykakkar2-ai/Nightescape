# ABTalks — Build in Public 🔥

**Build 1 real-world project every day across AI, Data Science, or Software Engineering.**
Submit your daily GitHub commit and LinkedIn breakdown to build an unshakeable proof-of-work portfolio.

## 📖 About

ABTalks is a **60-Day Proof of Work Challenge** platform. It gives learners a daily build task in one of three tracks, tracks their streak and progress with a GitHub-style contribution heatmap, and showcases community submissions on a live "Proof Wall" — turning consistent daily building into a public, shareable portfolio.

## ✨ Features

- **60-Day Streak Tracker** — Track your current streak, day count, and overall challenge progress (e.g. `Day 28 / 60`).
- **Streak Protection (Shields)** — Automatically absorb a missed daily check-in to preserve your streak record.
- **Contribution Heatmap** — A 60-block, GitHub-style heatmap showing Completed, Missed, and Upcoming days. Click any block to inspect that day's proof status.
- **Today's Focus** — A daily featured task card (e.g. *"Build a RAG Agent"*) linking straight to that day's challenge.
- **Choose Your Track** — Pick a daily track tailored to your career path:
  - 🔥 **AI & Agentic Systems** — Build RAG agents, MCP servers, and LLM pipelines over 60 days.
  - ⭐ **Software Engineering** *(Popular)* — Master full-stack React, Node.js, and system architecture with real-world builds.
  - 🆕 **Data Science & Analytics** — Deep dive into PyTorch, ETL pipelines, and predictive analytics models.
- **Daily Task Pages** — Each day includes a task brief, key objectives, and an architectural blueprint (e.g. `Day 12: Build a Custom KB Chatbot`).
- **Live Proof Wall** — Real-time feed of student submissions with links to their code and LinkedIn/post write-ups.
- **Dashboard Demo States** — Preview the dashboard in different states: Active Streak, Empty Profile (Day 1), or Missed Day.
- **Cohort Leaderboard Rank** — See your rank among all enrolled students (e.g. `Rank #42 of 1295`).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/princykakkar2-ai/Nightescape.git
cd Nightescape/Frontend/abtalks-landing-page

# Install dependencies
npm install

# Start the development server
npm start
```

The app will be available at [http://localhost:3000](http://localhost:3000).
